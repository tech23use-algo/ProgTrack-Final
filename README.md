# ProgTrack

ProgTrack is a goal-tracking web application 

The current version contains the frontend interfaces for:
- Registration
- Login
- Dashboard

# Switch between register, login and dashboard interface

## Clone the repository in your device first

- Type 'register' in file app.jsx, line number 9, useState(___) to view registration page
- Type 'login' in file app.jsx, line number 9, useState(___) to view login page
- Type 'dashboard' in file app.jsx, line number 9, useState(___) to view dashboard page
